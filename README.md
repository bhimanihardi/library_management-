# 📚 Library Management System

A simple **Python-based Library Management System** that helps manage books, members, and library transactions through a console-based application. It uses JSON files to store library data.

## ✨ Features

- **Member Registration:** Register new library members.
- **Member Login:** Login using a registered member name.
- **Add Books:** Add new books with author, price, and available copies.
- **Update Books:** Update book prices and available copies.
- **Display Books:** View all available books and their details.
- **Issue Books:** Issue books to registered members.
- **Return Books:** Return previously borrowed books.
- **Purchase Books:** Purchase books and record transactions.
- **Transaction History:** Display library transaction records.
- **JSON Data Storage:** Store books, members, and transactions in JSON files.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Data Storage:** JSON
- **Modules:** `json`, `datetime`, `random`, `os`

   ```bash

   ```

   ```bash
   cd Library-Management-System
   ```

3. Run the Python file:

   ```bash
   python library_management.py
   ```

4. Register or log in to access the library menu.

## 💾 Data Storage

The project uses three JSON files:

- `books.json` – Stores book details, prices, authors, and available copies.
- `members.json` – Stores member information and borrowed books.
- `transactions.json` – Stores library transaction records.
